# SET A – Library Book Management API

B.Tech Second Year | Full Stack Development

## Setup

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. The API runs at `http://localhost:3000`.

## Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/books` | Get all books |
| POST | `/api/books` | Add a book |
| GET | `/api/books/filter?author=Paulo` | Filter by author (case-insensitive partial match) |
| GET | `/api/books/:id` | Get one book |
| PUT | `/api/books/:id` | Replace/update a book |
| DELETE | `/api/books/:id` | Delete a book |

Data is stored in an in-memory JavaScript array and resets when the server restarts.

## Example POST/PUT body

```json
{
  "title": "The Discovery of India",
  "author": "Jawaharlal Nehru",
  "genre": "History",
  "publishedYear": 1946,
  "available": true
}
```

All five book fields are required. `publishedYear` must be an integer and `available` must be a boolean. IDs are generated by the API and cannot be supplied or changed by clients.

## Test

Use Postman or Thunder Client. Set the request body type to JSON for POST and PUT. Check both valid and invalid IDs and bodies, and try a filter with an author that has no matches.
